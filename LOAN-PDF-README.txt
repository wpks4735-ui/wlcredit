WL Credit 1.1.0 - 单一PDF（内嵌视频）

部署及使用
1. 将本 ZIP 内 wlcredit-main 的文件更新到现有网站项目并部署。
2. 刷新后台，打开已通过贷款的客户详情，重新点击“下载 PDF”。
3. 把下载出来的 PDF 发给客人或老板即可，收件人无需网站账号或专属链接。
旧 PDF 不会自动改变，必须在更新后重新生成。项目 ZIP 是给网站更新用的，客人收到的是生成的 PDF。
本次不需要新增 SQL。上次银行迁移已完成则不用再执行。

文件内容
中英双语客户资料、个人银行、两位紧急联系人、单笔贷款的到手金额/利息/独立清账金额。
不显示还款具体日期和状态，不显示生成时间及附件目录说明。
条款保留到期日11:59前还款、迟还RM200/天、付利息不抵扣清账金额。
本功能只更改导出，不改变已有记账与计费逻辑。
照片：连续照片每页最多4张，原图按比例显示，可使用PDF阅读器放大。
PDF上传文件：原文件全部页面保留，前面有文件名分隔页。
视频：原始字节嵌入PDF附件，不再输出后台观看链接，不设置有效期或密码。
视频页放在整个文件末尾；多段视频各有一页，带封面、回形针附件入口和说明。
PDF附件面板也能找到 video-N.mp4 / .mov / .webm；原文件名保存在附件描述中。
附件内部用唯一编号，避免原始文件同名造成覆盖。

收件人如何观看视频
用支持PDF附件的阅读器打开PDF，点击末尾视频页的回形针图标，或打开阅读器的附件面板。
先保存/提取视频到设备，再使用设备的视频播放器播放。
不保证手机、WhatsApp、微信或浏览器内置PDF预览能打开视频附件；这是用户已接受的阅读器限制。
视频随PDF一起传递，离线亦可提取，不依赖原网站是否存在。
PDF通常会接近视频原文件大小，发送平台自身的文件大小上限仍适用。

兼容与限制
无法解码视频封面时仍保留视频原文件并显示附件说明。
导出时需要后台用户有权限读取客户附件；下载、查询、解析失败会终止并报出文件名，不悄悄丢弃附件。
单个视频最大200MB，全部视频合计最大350MB；单个非视频附件最大80MB。
中文说明页与照片由浏览器高清绘制，支持查看/打印/放大，说明页文字不是可搜索文本。
已上传PDF原页继续保留原内容。
