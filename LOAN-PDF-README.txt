LOAN PDF 下载功能 - 使用与部署说明

部署
将本 ZIP 的 wlcredit-main 文件更新到现有网站项目并重新部署。
本次 PDF 功能不需要新增 SQL，也不需要新建 Storage bucket 或开放公共读取权限。
本包保留上次的客户银行修复。如果上次银行 SQL 已执行，无需重跑；未执行则先运行 WL-CREDIT-CUSTOMER-BANK-FIX.sql。

使用
1. 建立客户并上传图片、PDF、视频。
2. 贷款完成审批并成为正式贷款记录后，打开客户详情。
3. 页面顶部显示“贷款资料 PDF”，每笔符合条件的贷款各有一个下载按钮。
4. 点击相应贷款按钮，等待读取附件与生成。下载文件含中英双语资料及附件。
状态 approved / active / overdue / paid / completed 可下载；pending 等未通过状态不可下载。
仅有审批中的申请、尚未创建正式贷款记录时不会显示按钮。

内容
客户个人资料、银行资料和两个紧急联系人；对应贷款的 principal（到手金额）、interest（每期利息）、settlement_amount（独立清账金额）、放款日期。
金额直接读取单笔贷款，不使用客户汇总金额，不将利息与清账相减。
载明到期日晚上11:59前还款（马来西亚时间）、迟还RM200/天、付利息不减少清账金额。
本功能生成文件中的说明，不改动现有记账、计息或逾期计费逻辑。
该文件按生成时当前资料读取，不是不可变的审批历史快照。

附件
图片：按比例加入完整图片页，支持 JPEG / PNG / WebP。
PDF：保留原文件全部页面，加入文件标题分隔页。
视频：尝试截取封面；浏览器不能解码或无法截帧时显示说明，仍保留可点击观看链接。
视频链接指向原网站后台，通过现有登录与 Storage 权限读取。
PDF 本身不嵌入视频播放数据，不提供匿名分享；收件人没有授权后台账号时无法观看。
链接不保存短期 Storage token；每次进入后台观看页重新生成一小时有效的播放地址。
网站域名或附件路径变化、附件删除、账号权限撤销会影响观看。
客户资料上传表及关联申请中的 document_paths 一并读取，并按 bucket/path 去重。
如果查询、下载、加密PDF解析或附件类型不支持而失败，停止本次导出并报出原因；不悄悄省略文件。
单个非视频附件限80MB；附件多时生成时间和内存消耗会增加。
PDF中的中英文字以浏览器高清绘制，阅读与打印正常，但生成的说明页文字不能像原生文字PDF一样搜索或复制；原PDF附件仍保留原文件内容。
