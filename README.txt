WL Credit 精简更新包 1.3.0（29个文件）

本次：客户详情下载按钮改为“下载资料包 / Download ZIP”。
每笔已通过的贷款生成一个独立ZIP，可转发给客人或老板。

客户资料包内
00-Contents.txt：文件目录及转账凭证缺失提示。
01-Customer-Loan.pdf：现有中英双语贷款PDF，包含客户上传资料及本笔转账截图；原PDF和视频仍以内嵌附件保留。
02-Customer-Details.txt：可复制的客户基本资料、个人银行、两位紧急联系人、单笔到手金额、每期利息、独立清账金额、出账日期/时间。
03-Uploaded-Files：客户上传的全部原始图片、视频、PDF文件。
04-Transfer-Proofs：本笔贷款关联的转账截图/出款凭证原文件。
原文件名称前面加顺序编号，同名文件不会覆盖。
TXT使用带BOM的UTF-8和Windows换行，方便记事本查看中文。

出账信息与转账截图
金额读取当前这笔贷款的principal、interest、settlement_amount，不使用客户总额推算。
出账时间优先读取本贷款finance_disbursed_at/disbursed_at，再使用关联申请finance_disbursed_at；只有disbursement_date时只写日期。
有完整时间的记录转换为马来西亚时间。未记录则明确标注，不使用创建时间冒充出账时间。
截图从本贷款及关联申请finance_proof_path、disbursement_receipts读取，按贷款及客户筛选，不混入其他贷款凭证。
若没有转账截图，目录明确写“本笔贷款未记录转账截图”；不能凭空补出未保存的文件。
下载或读取报错会停止生成并显示文件名，不输出缺文件的资料包。

部署
解压本项目ZIP，将 wlcredit-main 内的文件和文件夹上传到原项目根目录并覆盖同名文件，保留目录结构。
网站部署后刷新后台并重新下载资料包；旧下载文件不会自动改变。
本次无需SQL，适用于已经正常运行的网站与已存在的出款凭证表。
生成ZIP需要页面现有JSZip组件加载成功；读取仍按当前后台账号权限执行。
PDF和ZIP同时保留附件，ZIP体积会比原始资料总和大；用户收到ZIP需解压查看原文件。
