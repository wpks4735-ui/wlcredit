WL Credit V17 — Unified Customer Username

Deployment order:
1. Run V17-UNIFIED-CUSTOMER-USERNAME.sql in Supabase SQL Editor.
2. Confirm username and customer_code are identical (WL001, WL002, ...).
3. Upload all website files to the GitHub repository root.
4. Wait for Cloudflare Pages deployment, then close old tabs and reopen the site.

Customer ID shown in the UI = login username = customers.username.
The legacy customer_code column is retained only as a synchronized compatibility alias for existing database RPCs.
